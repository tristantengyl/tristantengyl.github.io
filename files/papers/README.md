# Author PDFs

Place author-permitted paper PDFs in this directory. Each file should use a stable, URL-safe filename, for example:

```text
covertauth-ton-2026.pdf
```

After a PDF is added, update its corresponding `PDF` control in `_pages/about.md` from a muted `<span>` to a link such as:

```html
<a class="paper-button" href="/files/papers/covertauth-ton-2026.pdf">PDF</a>
```

Only upload versions that are permitted by the publisher's author-sharing policy.
